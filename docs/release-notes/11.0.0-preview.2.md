This is a preview release of WebSharper 11.0.

## Fixes

* #1622 Fixed F# `unit` values compiling to `null` in some places and to `undefined` in others, so that structural equality treated them as different: `ignore 1 = ()` and `Ok (ignore 1) = Ok ()` were `false`. Unit values now compiled to `undefined` everywhere:
  * the `()` literal, for example in `Some ()` or `Choice1Of2 ()`;
  * `Unchecked.defaultof<unit>`;
  * a unit argument dropped from a call and then substituted into an inline member, such as a computation expression builder's `Yield(())`;
  * the result of an inlined unit-returning lambda, and a unit argument restored when a curried call was uncurried.

## Breaking changes

* #1622 `box ()` was now `undefined` instead of `null` in JavaScript, so `box () = null` was `false` (it had been `true`, as on .NET). Structural equality still treated `null` and `undefined` as different values.
