This is a preview release of WebSharper 11.0.

## Features

* #1618 Made the `WebSharper.FSharp` and `WebSharper.CSharp` packages much smaller (about 15 MB and 12 MB instead of 128 MB and 88 MB) by including only the portable compiler, and added the ReadyToRun compilers as the optional `WebSharper.FSharp.Booster` and `WebSharper.CSharp.Booster` .NET tools for Windows, Linux, and macOS on x64 and arm64. Install them for the full compilation speed: the build used a tool when it was installed at exactly the WebSharper version the project referenced, and the portable compiler otherwise.
  * Added `dotnet ws compiler status` and `dotnet ws compiler sync` to the latest `dotnet ws` (`dotnet tool update -g dotnet-ws`) to manage the tools. `status` showed which compiler each project built with, and `sync --local` added the tools at the project's WebSharper version to the repository's tool manifest (`--global` installed them globally). Run `dotnet ws compiler sync` again after updating WebSharper. Installing the tools required .NET SDK 10 or newer.
  * Added warning WSB9101 for a tool manifest listing a Booster tool of another WebSharper version, and WSB9102 for a listed tool that was not restored. `WebSharperUseBoosterTool=false` turned the tool lookup off.
  * Made the booster (wsfscservice) also run with the portable compiler, so F# builds used it on every platform.
