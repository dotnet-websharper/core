This is a preview release of WebSharper 11.0.

## Fixes

* #1621 Fixed dead code elimination removing `Dictionary` members that were only called through the `IDictionary<'K, 'V>` or `IReadOnlyDictionary<'K, 'V>` interfaces, for example on the result of `dict` or `readOnlyDict`, or through an F# member constraint such as FsToolkit.ErrorHandling's `ValueOption.tryGetValue`. A bundle with such a call failed at run time with an error like `dict(...).TryGetValue is not a function`, unless other code called the member on a `Dictionary` directly. The `Dictionary` proxy now declared these interfaces, so their `TryGetValue`, `ContainsKey`, `Item`, `Keys`, `Values`, `Add`, and `Remove` members kept the matching `Dictionary` members.
