This is a minor release of WebSharper 10.1. NuGet version `10.1.8.681`.

Templates for .NET Core SDK: `dotnet new install WebSharper.Templates@10.1.8.681`

## Enhancements
* Faster builds: 
  * #1608 `wsfsc`, `wscsc` and the `wsfscservice` booster now run with Server GC (non-concurrent), like `fsc` and `csc`.
  * The F# type check needed for WebSharper translation now uses the F# compiler service's TransparentCompiler, which type checks files in parallel. This applies to both standalone compilation and the `wsfscservice` booster. Opt out system-wide with the `WebSharperTransparentCompiler` environment variable set to `false`, or per project with `"transparentCompiler": false` in `wsconfig.json`, the `WebSharperTransparentCompiler` MSBuild property set to `false`, or the `--transparentcompiler-` flag.

## Fixes
* #1607 `wsfsc` "Global error" messages now include the stack trace of the original exception, not only the compiler's worker-thread wrapper.
