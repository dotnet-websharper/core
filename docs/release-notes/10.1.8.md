This is a minor release of WebSharper 10.1. NuGet version `10.1.8.681`.

Templates for .NET Core SDK: `dotnet new install WebSharper.Templates@10.1.8.681`

## Enhancements
* #1608 Faster builds: `wsfsc`, `wscsc` and the `wsfscservice` booster now run with Server GC (non-concurrent), like `fsc` and `csc`.

## Fixes
* #1607 `wsfsc` "Global error" messages now include the stack trace of the original exception, not only the compiler's worker-thread wrapper.
