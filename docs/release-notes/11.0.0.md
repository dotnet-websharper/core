## Features

* #1601 Add .NET 11 as a target framework option and the default for all project templates.
  * Add the .NET 11 `MemoryExtensions.Min` and `Max` span overloads, which are now selected for array extension calls.
  * Support `ReadOnlySpan<T>.ToArray` in collection builder methods.
* #1600 Translate C# 15 collection expression arguments, union declarations and patterns, extension indexers, and labeled `break` and `continue`.
  * Added the `Enumerable.Chunk` proxy using the shared `Seq.chunkBySize` implementation.
* #1599 Support FSharp.Core `partitionWith` for arrays, lists, sets, and parallel arrays in JavaScript, with tests for record spreads, extension operators, and all-fields record constructors.
  * Preserve resolved F# extension operators in generic inline calls.

## Fixes

* #1600 C# language fixes:
  * Preserve local functions, ordinary loop jumps, and `finally` semantics when lowering C# labeled control flow.
  * Resolve inherited C# interface members when translating implementations, including enumerator `MoveNext` and `Dispose` methods.
